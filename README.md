# Student Productivity Tracker

A beginner-friendly C project to help students organize tasks, track exams, plan study time, and review progress.

## Planned features

- Task manager: add, view, complete, and delete tasks
- Exam tracker: save subjects and exam dates
- Study planner: record daily study sessions
- Progress report: summarize completed tasks and study activity
- File handling: keep records between program runs

## Current status

**Stage 1:** Main menu and input handling.

More features will be added step by step as the project develops.

## Build and run

With GCC:

```bash
gcc main.c -o tracker
./tracker
```

On Windows PowerShell:

```powershell
gcc main.c -o tracker.exe
./tracker.exe
```

## Learning goals

This project practices C fundamentals including functions, loops, conditional statements, structures, arrays, and file handling.
